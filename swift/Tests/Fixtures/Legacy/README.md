# Legacy save fixture

Synthetic user progress on the first two actual bundled structures and ghost 101. Field names match the saved JSON format in source baseline c7f3a33; this is not private user data or an export from a released binary. Structure 1 is visited, opened and liked, and ghost 101 is visited. Structure 2 omits optional progress fields to exercise old/default decoding. Test defaults supply seven visit days. The fixture is read directly, not encoded by the new model implementation.
